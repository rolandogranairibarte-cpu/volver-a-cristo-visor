# Visor online de Volver a Cristo

Este paquete contiene un visor personalizado basado en PDF.js 3.11.174.

## Archivos
- index.html — visor
- volver-a-cristo.pdf — PDF del libro

## Publicación
La forma más sencilla es subir esta carpeta a un alojamiento estático, por ejemplo GitHub Pages.
Después, en Google Sites se inserta la URL pública del `index.html` como contenido incrustado.

El visor no muestra botones de descarga o impresión, pero esto NO impide una descarga técnica del PDF: cualquier PDF que se visualiza en un navegador llega al dispositivo del visitante.

## Nota
El índice lateral es propio de este visor y no depende de los marcadores internos del PDF.
